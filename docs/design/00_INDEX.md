## 一句话论点

全国高血压**治疗率 45.8%，控制率只有 16.8%**。
药已经开了、也拿回家了——**掉下去的那 29 个百分点，绝大部分不在医院里，在家里。**
这段是现有一切医疗基础设施的盲区。

---

## 三层痛点

| 层 | 痛点 | 为什么现有方案不行 |
|---|---|---|
| **P1 执行** | 该吃的药没按时吃 | 智能药盒和闹钟已解决大半。**不在这层做差异化** |
| **P2 理解** | 不知道自己在吃什么 | 84% 看不清说明书、58% 看不懂术语。**药盒不知道盒子里是什么** |
| **P3 事实** | 远程子女拿不到真实情况 | 每条信息都经过一个有动机或有损伤的过滤器 |

**P1 建立习惯 → P2 建立不可替代性 → P3 建立付费意愿。**
三层共用同一个按钮，后两层边际成本接近零。

---

## 不可越的红线

1. **只做转录 / 对比 / 放大**，绝不解释医学含义
   → 越线即落入医疗器械监管，注册周期以年计。**这不是道德题，是能不能上线**
2. **AI 解析 → 子女逐条确认 → 才生效**，永不全自动
3. **记录事件，不记录内容**（不做常开麦克风 / 摄像头）
4. **数据绝不能当作考核护工的 KPI** —— 那会直接制造假数据
5. **说出口的承诺必须是真的** —— 投递确认前不说"已经告诉你女儿了"

## 三个交付物

1. **大字用药表**（图片）→ 一键设成老人手机**锁屏** / 发家庭微信群
2. **老人端 APK**——闹钟式三按钮：`吃了` / `等会儿吃` / `这次不吃`，
   外加`长按说话` 和 `给医生看`（诊室里点一下全屏，直接把手机递给医生）
3. **子女端手机网页**——拍照建档、逐条确认、收升级、回复回传

> **这个产品从头到尾不需要一张纸。** 没有打印、没有扫描、没有任何外设。
> 全部载体只有两样：**老人的安卓手机、子女的微信。**
> 每多一个硬件依赖，就多一批装不上的家庭。

## 视觉规范

- 主按钮绿 `#0B6B33`（白字对比 7.4:1，AAA）
- 品牌黄 `#FFD500` + 纯黑 `#0A0A0A`（对比 15:1）
- **颜色不承载信息**：转成灰度仍可用
- 老人端最小字号 24sp，主信息 ≥ 40sp
- 全部点击，不用滑动

## 头号技术风险

**国产 ROM 杀后台**，不是 LLM 效果。一个不会响的提醒 App 等于零。
第 6–8 天必须先打通三层防护（`USE_EXACT_ALARM` + 前台服务 + 厂商白名单引导），
**真机连续 72 小时漏响 0 次**才允许进第 11 天。详见 05 §4。

**测试机新旧两头都要有。** 目标用户的旧鸿蒙机（API 31）**恰恰暴露不出**
Android 14+ 的权限问题；新机又暴露不出低端 SoC 的冷启动问题。
任一头单独测通都不算数。

**装机只做两件事**（不做健康监控）：

1. **能不能装** —— 网页在下载前判断，装不了直接说 + 给替代方案
2. **要开哪些权限** —— 一屏，按机型给步骤 + 一键跳设置

> ⚠️ **华为纯净模式需要华为账号才能退出**，是装机流程最可能卡死的一步。
> 老人多半不记得密码 → 子女用自己账号临时登。
