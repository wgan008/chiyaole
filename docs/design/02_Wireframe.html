贯穿全部老人端界面的四条铁律

① 没有导航。没有底部 Tab、没有返回键逻辑、没有菜单、没有设置、没有登录。任何一屏都是终点。

② 全部是点击。绝不使用滑动、长按拖拽、双击。（唯一例外：「长按说话」，因为它模仿微信语音，已被学会。）

③ 不隐藏。不做"点开更多"的渐进披露——藏起来的 UI 对这个人群等于不存在。

④ 不评分。永远不向老人展示依从率、连续天数、打卡日历。任何计分都会制造说谎的动机。

⑤ 颜色不承载信息。每个色块都必须有文字。 红绿色弱约影响 8% 男性，白内障还会把整个画面黄化并降低对比—— 把界面转成灰度看一眼，如果还能用，才算过关。

一次设计修正

初稿里有一张"待机屏"，默认 App 常驻在屏幕上。这是错的。 手机是老人的，不是这个应用的——他要用微信、要接电话、要看照片、要刷视频。 一个霸占屏幕的健康 App 会被直接卸载，而且会被子女认为很可疑。

正确的模型：App 绝大部分时间完全不在屏幕上。它只在三个时刻出现—— 到点时、有待办时、老人主动打开时。

三条必须处理的例外

① 通话中不接管。老人正在打电话（尤其是和子女视频）时到点， 推迟到通话结束后再响。打断一次通话，产品就会被关掉。

② 永远不劫持返回键。任何一屏按返回／Home 都能立刻离开。 留人的 App 在这个人群里会引发恐慌——"这个东西关不掉了"。

③ 不申请无关权限。不要通讯录、不要位置、不要相册。 权限弹窗越多，子女越怀疑这是骗老人的软件。

D子女端（手机网页，微信里直接打开）

正常成年人使用，可以有正常的信息密度。用 URL 里的随机 token 进入，无需注册登录。

先说清楚：子女端是「手机上的网页」，不是电脑网页

子女在微信里收到一条链接 → 点开 → 就在手机上拍照。 「Web」指的是交付形态（网页，零安装），不是使用设备。 拍照当然是手机拍——但用网页调起手机相机，而不是让子女再装一个 App。

为什么子女端也不做 App？个人主体同样上不了应用商店（和老人端一个问题）， 而让子女也侧载 APK 会在最需要说服他的那一刻增加摩擦。 微信里点一个链接，是中国最自然、阻力最小的路径——冷启动阶段任何摩擦都是致命的。

一个必须面对的技术现实：微信浏览器里能做什么相机
方案POC 可用说明
<input capture>
调起系统相机		 ✓ 可靠 零依赖，安卓/iOS 微信内均稳定。代价：不能画自定义取景框、不能做实时提示
getUserMedia
网页内实时预览		 不稳 能画取景框和实时反馈，但在微信内置浏览器里支持不稳定， iOS 尤其。POC 不能押在这上面
微信 JS-SDK
wx.chooseImage		 ✕ 拿不到 体验最好，但需已认证的服务号 + JS 安全域名配置 → 个人主体拿不到（同 §01 的资质约束）

所以 POC 的方案是：调系统相机拍 → 上传 → 服务端 VLM 检查 → 有问题就说"重拍一张"。 把实时反馈改成拍后反馈，多一次往返，但零依赖、100% 可用。

而且这样反而更好：浏览器端的模糊检测本来就不准； 而"信息够不够"这个判断无论如何都必须由服务端 VLM 来做—— 统一成"拍完再说"，逻辑更一致。实时取景留到 v2 做原生 App 时再上。

拍照环节的四条设计原则
原则为什么
不写使用说明 没人读。改成 AI 看完照片后提具体要求—— 「请翻到写着用法用量那一面」比「请拍摄完整包装」有效一个量级
反馈在拍之后
不在取景时		 微信浏览器里 getUserMedia 不稳定，画不了实时取景框。 但服务端反馈反而更具体——能说出"第 2 页挡住了 3 行"， 而不只是"太糊了"
批量拍，统一校对 逐盒确认会让 5 分钟变成 20 分钟。先全拍完，再一次性核对
永远留手动出路 拆零分装、盒子磨损、进口药——总有拍不出来的。 没有手动填写，这些用户直接流失
原图永久保留 VLM 会看错且看错时很自信。原图是唯一的仲裁者， 且模型升级后可重跑历史数据
这一屏的转化率决定整个产品

第 11 天上门时要计时：从打开链接到拍完，实际用了几分钟？中途放弃了吗？ 如果子女在这一步就退出，后面所有设计——按钮、语音、事实层——一个都不会发生。

所以这 5 分钟必须当场兑现。初稿指望「打印贴冰箱」， 但多数家庭没有打印机——现在改由 D3 的「试听」承担（听到那句话的情绪冲击）， 加上 大字用药表图片发家庭群 / 设成锁屏。两者都不需要任何硬件。

为什么必须是三态

系统记录的是「按了按钮」，不是「吃了药」。 把可疑的那条如实标出来，而不是混进"已确认"里凑一个好看的依从率—— 虚假确定性比没有数据更危险，子女会因此放松警惕。

永远不显示"依从率 92%"这样的单一数字。这份数据适合发现变化和触发一通电话， 不适合下绝对结论，更不能当作考核护工的 KPI。

这一屏为什么没有一句"解读"

产品对检查报告只做三件机械的事：转录（把单子上已印的数值和参考范围搬过来）、 对比（做减法）、放大（字号与语音）。

绝不写「这提示肾功能下降」——那是行医，个人主体没有任何资质， 而且会让产品被认定为医疗器械，注册周期以年计。 「建议问医生这 3 个问题」是安全的：它帮人提问，不替人判断。
